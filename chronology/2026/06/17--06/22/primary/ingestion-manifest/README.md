## Важное ограничение

Через текущий GitHub-коннектор фактически доступные операции записи принимают либо UTF-8 текст, либо blob content как строку/base64. Прямой параметр вида `file_path` для загрузки готового ZIP из `/mnt/data` отсутствует.

Поэтому этот файл фиксирует созданный архив и его контрольные данные, но **сам бинарный ZIP ещё не загружен в репозиторий как файл**.

Это не закрывает требование пользователя полностью. Требование остаётся открытым до фактической загрузки бинарного архива или до появления инструмента/параметра, который принимает локальный файл как вложение.
