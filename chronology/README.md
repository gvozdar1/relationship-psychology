# Хронология проекта

Папки сортируются по **дате события**, а не по дате переноса файла в репозиторий. Диапазон в имени означает, что один документ охватывает несколько дней.

## Правило размещения

1. Если известна точная дата события — `chronology/YYYY/MM/DD/...`.
2. Если известны год и месяц, но день не подтверждён — `chronology/YYYY/MM/undated-day/...`.
3. Если год/месяц события нельзя надёжно установить — `chronology/undated/...`.
4. Если документ датирован датой создания/аналитической обработки, а не датой самого события, он относится в `project/context/YYYY/MM/DD/`, `project/updates/YYYY/MM/DD/` или `project/audits/YYYY/MM/DD/`.
5. Недостающую дату **не угадывать** ради красивой папки. Человечество и без того неплохо умеет превращать предположения в «факты».
