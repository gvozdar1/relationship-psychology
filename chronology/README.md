# Хронология проекта

Папки сортируются по **дате события**. Диапазон в имени означает, что один документ содержит несколько дней. Дата `undated` означает не «дата неизвестна нам на глаз», а что её нельзя подтвердить доступной первичкой.

| Период события | Содержание |
|---|---|
| 2026-04-27 | Символический контакт, забота, контекст Евгения — `04/27/` |
| 2026-04-29–05-14 | Полный экспорт переписки `messages12.html` — `04/29--05/14/` |
| 2026-05-04–07-16 | Социальный ресурс, 16.07 и цифровой контур — `05/04--07/16/` |
| 2026-05-07–05-29 | Майские эпизоды, границы и формат — `05/07--05/29/` |
| 2026-06-13–06-20 | Минский пролог — `06/13--06/20/` |
| 2026-06-17–07-15 | Непервичная реконструкция непрерывности — `06/17--07/15/` |
| 2026-06-17–06-22 | Минск, офлайн-реконструкция — `06/17--06/22/` |
| 2026-06-21–06-23 | Проводы и пост-отъездной контакт — `06/21--06/23/` |
| 2026-06-27–08-05 | Threads и коррекции 02–05.08 — `06/27--08/05/` |
| 2026-07-06–07-08 | Плотность контакта, TikTok, SRC-0018 — `07/06--07/08/` |
| 2026-07-26–08-06 | Просадка/возврат и SRC-0010 — `07/26--08/06/` |
| 2026-08-05–08-06 | Первичные карточки SRC-0003 и SRC-0004 — `08/05--06/` |
| 2026-09-10–09-12 | Значимость, баланс, Анапа/Вова — `09/10--09/12/` |
| Без подтверждённой даты события | `undated/`: декабрьский фрагмент, «дорогой», «Крискислис», Кая и таро-контекст |

Точный статус и сила каждого источника — в `../08_SOURCE_REGISTRY.md`.
