# Relationship Psychology

Закрытый рабочий архив проекта «Психология отношений: Крис».

## Главное правило
**Источник ≠ факт ≠ гипотеза ≠ вывод ≠ эмоциональная интерпретация.**

## Иерархия истины проекта
При конфликте рабочих документов:
1. `09_COMBINED_MASTER.md`
2. `00_INDEX.md`
3. более поздние датированные журналы/дополнения и прямые источники
4. остальные аналитические документы

Внутри любого документа прямая цитата или наблюдаемое действие не превращает интерпретацию мотива в факт.

## Основные документы
- `00_INDEX.md` — карта проекта.
- `01_METHOD.md` — метод аналитической проверки.
- `01_PROJECT_CORE.md` — предметное ядро проекта.
- `02_TIMELINE.md` — единая хронология.
- `03_HYPOTHESES_AND_CONFIDENCE.md` — гипотезы и уверенность.
- `04_SIGNAL_MATRIX.md` — сигналы и альтернативные объяснения.
- `05_COMMUNICATION_PROTOCOL.md` — правила разбора сообщений.
- `06_DECISION_MATRIX.md` — решения.
- `07_UPDATE_PROTOCOL.md` — протокол внесения новых данных.
- `08_SOURCE_REGISTRY.md` — реестр источников.
- `09_COMBINED_MASTER.md` — главный сводный документ.
- `10_*`–`13_*` — специальные доказательные и обновляющие документы.

## Разделы
- `kris/` — датированные дополнения по Крис.
- `sources/` — первичные и сырые текстовые источники.
- `ex-wife/`, `family/` — отдельные контуры.
- `references/` — методологические материалы.

## Маркировка
- **SOURCE** — прямой источник.
- **FACT** — наблюдаемое/прямо зафиксированное событие.
- **REPORT** — слова участника о событии.
- **HYPOTHESIS** — интерпретация.
- **CONCLUSION** — вывод из нескольких данных.
- **EMOTIONAL INTERPRETATION** — субъективное прочтение эмоционального смысла.
- **UNKNOWN** — данных недостаточно.
