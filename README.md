# Relationship Psychology

Закрытый рабочий архив для анализа отношений, хронологии, исходных переписок и психологических гипотез.

## Главное правило

**Источник ≠ факт ≠ интерпретация ≠ вывод.** Они хранятся раздельно.

## Иерархия документов

1. `09_COMBINED_MASTER.md` — сводная проверенная версия.
2. `00_INDEX.md` — карта проекта.
3. `02_TIMELINE.md` — хронология.
4. `03_HYPOTHESES_AND_CONFIDENCE.md` — гипотезы и уровень уверенности.
5. `04_SIGNAL_MATRIX.md` — наблюдаемые сигналы и альтернативные объяснения.

7. `06_DECISION_MATRIX.md` — решения и критерии.
8. `07_UPDATE_PROTOCOL.md` — как добавлять новые данные.

## Разделы

- `kris/` — материалы по Крис.
- `ex-wife/` — материалы по бывшей жене.
- `family/` — семейная динамика.
- `sources/` — исходники, транскрипты, скриншоты, экспортированные чаты.
- `references/` — книги, статьи и методология.

## Стандарт доказательности

Каждое утверждение маркируется как:

- **SOURCE** — прямая цитата/скриншот/файл.
- **FACT** — факт, подтверждённый источником.
- **REPORT** — слова участника, которые сами по себе ещё не доказывают событие.
- **HYPOTHESIS** — интерпретация.
- **CONCLUSION** — вывод, основанный на нескольких подтверждённых данных.
- **UNKNOWN** — данных недостаточно.

При конфликте документов приоритет имеет первичный источник и более поздняя сверенная версия.
