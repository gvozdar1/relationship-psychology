# Relationship Psychology

Закрытый репозиторий проекта «Психология отношений с Крис».

## Что является рабочей истиной

1. `09_COMBINED_MASTER.md` — объединённая проверенная версия.
2. `00_INDEX.md` — карта проекта и ограничения полноты.
3. `08_SOURCE_REGISTRY.md` — реестр происхождения данных.
4. Первичный файл имеет приоритет над аналитической формулировкой.

## Структура без смешения ролей

- Корневые `00`–`14` — аналитическая база отношений.
- `sources/` — рабочие карточки источников и происхождение новых материалов.
- `archive/` — неизменяемые исторические пакеты и первичные файлы.
- `archive/kris-project-2026-08-23/` — полный срез всей первички, которая физически была доступна при консолидации 23.08.2026.
- `narrative/` — отдельный художественный слой. Он не является доказательством событий, мотивов или чувств реальных людей.
