# Психология отношений с Крис

Закрытый репозиторий проекта. Он организован по роли документа и по **дате события**, а не по дате случайной загрузки.

## Главный источник истины

1. `09_COMBINED_MASTER.md` — действующий канон.
2. `00_INDEX.md` — навигация и граница полноты.
3. `08_SOURCE_REGISTRY.md` — происхождение и статус каждого источника.
4. Первичный носитель сильнее аналитической формулировки.

При конфликте приоритет: `09_COMBINED_MASTER.md` → `00_INDEX.md` → первичный источник → другие документы.

## Структура

- `chronology/YYYY/MM/…/` — материалы отношений по фактической дате события; внутри разделены `primary`, `derived`, `analysis`, `reconstructions`.
- `chronology/undated/` — материалы, для которых дата самого события не установлена. Дату не придумываем.
- `project/` — аудиты, контекст, реестр и методические документы, разложенные по дате создания.
- `archive/` — исторические срезы, импортированные пакеты и вытесненные версии. Не является текущим каноном.
- `archive/non-project/` — сохранённые, но исключённые из активного проекта материалы «Семейного пантеона».

## Быстрый старт

Открой `00_INDEX.md`, затем `09_COMBINED_MASTER.md`, затем нужную дату в `chronology/README.md`.

## Правила чтения

Каждая запись различает факт, пользовательский отчёт, гипотезу, вывод и эмоциональную интерпретацию. Повтор одного эпизода в сводке и в источнике не считается двумя независимыми доказательствами.
