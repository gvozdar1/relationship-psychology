# Mini stories

Самостоятельные боковые сцены, выросшие из основной линии проекта.

Они могут:
- развивать отдельный эпизод;
- показывать событие через фантастическую или мифологическую оптику;
- раскрывать персонажа без вмешательства в основную хронологию;
- становиться материалом для аудиосцен.

Каждый мини-сюжет хранится в тематической подпапке и помечается статусом `draft`, `canon` или `audio-ready`.
