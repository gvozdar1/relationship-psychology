# Audio scripts

Технические версии художественных текстов для многоголосой озвучки.

Каждый аудиосценарий должен однозначно указывать:
- имя говорящего перед каждой звучащей репликой;
- кто является рассказчиком;
- паузы и важные интонационные ремарки;
- какие ремарки не должны озвучиваться;
- используемый голос: реальный клон или цифровой персонаж.

Финальная аудиоверсия может отличаться по пунктуации и разбиению фраз от литературной версии, но не должна менять смысл без отдельной правки исходного текста.
