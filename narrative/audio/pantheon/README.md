# Pantheon audio status

## Критическое правило

`audio-ready` не означает «озвучено».

Часть считается фактически озвученной только после создания реального итогового звукового файла, который сохранён и доступен для прослушивания. Подготовленный Markdown-сценарий, workflow, лог рендера, временная дорожка или целевое имя файла сами по себе озвучкой не являются.
