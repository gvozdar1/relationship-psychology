# Pantheon audio status

## Критическое правило

`audio-ready` не означает «озвучено».

Часть считается фактически озвученной только после создания реального звукового файла, который можно прослушать. Подготовленный Markdown-сценарий, workflow, лог рендера или целевое имя файла сами по себе озвучкой не являются.
