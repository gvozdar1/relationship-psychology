# Оптимизированные пакеты скриншотов

Эта папка хранит ZIP-пакеты **производных WebP-копий** исходных скриншотов.

- исходники не считаются перенесёнными только потому, что существует этот архив;
- оригинальные имена файлов сохранены внутри ZIP;
- параметры WebP: ширина до 360 px, quality 32;
- точные оригинальные SHA-256 находятся в `../original_manifest.csv`;
- SHA-256 каждого ZIP фиксируется ниже.
