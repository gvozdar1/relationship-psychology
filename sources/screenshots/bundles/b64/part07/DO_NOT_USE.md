# QUARANTINE

Эта директория содержит неудачную раннюю попытку передачи bundle 07.

- `part00.b64` был передан из точного локального 18k-фрагмента и сам по себе корректен.
- `part01.b64` был создан после вывода слишком крупного фрагмента, который интерфейс усекал. Его содержимое **не считается проверенным и не должно использоваться для реконструкции**.

Каноническая повторная передача bundle 07 ведётся в соседней директории `../part07-v2/` только фрагментами безопасного размера с локальными SHA-256.

Наличие файлов в этой карантинной директории не означает миграцию bundle 07.
