# Уникальность локальных изображений

На текущем локальном срезе:
- 161 канонический номерной скриншот проекта;
- 15 opaque `file_...` копий из текущего чата, которые побайтово дублируют часть номерных файлов по SHA-256;
- следовательно, число уникальных канонических скриншотов остаётся **161**.

Отдельный `file_contact.jpg` не включён в архив проекта, поскольку его принадлежность к доказательной базе проекта не установлена.
