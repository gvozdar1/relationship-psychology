# Screenshot evidence archive

## Состояние переноса
На момент инвентаризации в локальном проектном пакете обнаружено **161 изображение** с именами `1000028787.jpg` … `1000029437.jpg` (с пропусками в нумерации), общий объём оригиналов **30 487 355 байт**.

Полный контрольный реестр оригиналов уже сохранён в:
- `original_manifest.csv` — исходное имя, размер, SHA-256, ширина, высота и фактический формат каждого из 161 файлов.

Важно: `1000029153.png` и `1000029154.png` имеют расширение `.png`, но фактический формат по декодированию — JPEG. Имена не исправляются задним числом: сохраняется имя исходного файла и отдельно фиксируется реальный формат.

GitHub-архив строится в два слоя:

1. `optimized/` — отдельные WebP-копии для быстрого просмотра в репозитории. Они уменьшены до ширины 360 px и сохранены WebP quality 32. Это **производные копии**, а не побайтовые оригиналы.
2. `bundles/` — ZIP-пакеты тех же оптимизированных копий с сохранением исходных цифровых имён файлов.

Оригинальные имена, размеры и SHA-256 фиксируются в `original_manifest.csv`. Оригиналы не объявляются перенесёнными, пока соответствующий бинарный blob не записан в GitHub.
