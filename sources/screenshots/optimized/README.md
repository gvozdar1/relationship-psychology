# Optimized screenshot copies

Эта папка содержит отдельные WebP-копии для быстрого просмотра. Это производные файлы, не первичные оригиналы.

Параметры текущего пайплайна: ширина до 360 px, WebP quality 32, сохранение исходного цифрового имени без расширения.

Полные наборы производных копий дополнительно пакуются в `../bundles/`.
