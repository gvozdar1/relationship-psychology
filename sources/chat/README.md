# Chat source archive

Этот каталог хранит снимки пользовательских чатов, связанных с проектом `relationship-psychology` и его художественным слоем `narrative/`.

## Правило

Чат сохраняется как источник контекста и происхождения решений, но его части имеют разный доказательный статус:

- **USER-DIRECTIVE** — указание пользователя по проекту, стилю, структуре или дальнейшей работе.
- **USER-REPORT** — сообщение пользователя о реальном событии; это пользовательский отчёт, а не автоматически подтверждённый факт.
- **ASSISTANT-FICTION** — художественный текст, созданный ассистентом; никогда не является доказательством реальных событий, мотивов или чувств реальных людей.
- **ASSISTANT-PROJECT** — проектное решение, структура, план, отчёт или техническая договорённость.

## Постоянное правило проекта

Новые содержательные сообщения текущего рабочего чата должны добавляться в этот архив последовательными снимками. Сырой чат служит источником для последующего разбора, но не подменяет `08_SOURCE_REGISTRY.md`, фактическую хронологию или первичные материалы.

Для художественной линии допускается использовать `ASSISTANT-FICTION` как уже созданный черновой/канонический материал после проверки и переноса в `narrative/`.
