### Технические действия

- Проверена официальная документация Fish Audio API: TTS endpoint `POST https://api.fish.audio/v1/tts`, авторизация Bearer API key, пользовательский голос задаётся через `reference_id`.
- Канонический `reference_id` Гвоздаря остаётся `3ae06a3f3ca64f4c93d6853f45bed33d`.
- Прямая попытка из локальной среды не дошла до Fish Audio из-за отсутствия внешнего DNS/сетевого доступа в sandbox; это не является проверкой валидности ключа.
- Replit не удалось использовать как безопасный промежуточный рендерер: создание нового приложения заблокировано требованием активной подписки.
- Подготовлен безопасный GitHub Actions workflow `.github/workflows/fish-audio-gvozdar-test.yml`. Он не содержит API-ключа и читает только `secrets.FISH_API_KEY`.
- Workflow генерирует короткий MP3-тест каноническим голосом и сохраняет его как GitHub Actions artifact.

## Правило безопасности

- API-ключи никогда не коммитить в репозиторий и не сохранять в `sources/chat/`.
- Для рабочего запуска использовать GitHub Repository Secret с именем `FISH_API_KEY`.
- Значение ключа, переданное в чат, считать чувствительным и не воспроизводить в ответах/файлах.
