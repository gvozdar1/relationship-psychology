# Протокол обновления

Когда появляется новый материал:

1. Сохранить исходник в `sources/` или дать на него ссылку.
2. Добавить запись в `08_SOURCE_REGISTRY.md`.
3. Обновить `02_TIMELINE.md` только фактами/сообщениями с корректной маркировкой.
4. Если материал влияет на гипотезу, обновить `03_HYPOTHESES_AND_CONFIDENCE.md`.
5. Если меняется общий вывод, обновить `09_COMBINED_MASTER.md`.
6. В сообщении коммита кратко писать, что изменилось и почему.

## Целостность идентификаторов источников
- перед выдачей нового `SRC-*` проверить `08_SOURCE_REGISTRY.md` и существующие заголовки файлов;
- один `SRC-*` может обозначать только один семантически самостоятельный источник;
- если второй файл является краткой сводкой, companion-файлом или производной карточкой того же материала, не выдавать ему новый или повторный `SRC-*`; явно маркировать его как companion/summary соответствующего источника;
- при обнаружении старой коллизии ID не переписывать историю молча: сохранить старое состояние в Git-истории, задокументировать отображение `старый ID → новый ID` и исправить активные ссылки;
- числовые префиксы аналитических update-файлов не считать идентификаторами источников: источники определяются только `SRC-*`, `CTX-*`, `AUD-*` и точным путём.

## Запреты
- не удалять неудобные старые версии без причины;
- не смешивать цитату и пересказ;
- не приписывать мотивы без маркировки `HYPOTHESIS`;
- не исправлять старую запись задним числом без объяснения изменения.
