# Протокол обновления

Когда появляется новый материал:

1. Сохранить исходник в `sources/` или дать на него ссылку.
2. Добавить запись в `08_SOURCE_REGISTRY.md`.
3. Обновить `02_TIMELINE.md` только фактами/сообщениями с корректной маркировкой.
4. Если материал влияет на гипотезу, обновить `03_HYPOTHESES_AND_CONFIDENCE.md`.
5. Если меняется общий вывод, обновить `09_COMBINED_MASTER.md`.
6. В сообщении коммита кратко писать, что изменилось и почему.

## Запреты
- не удалять неудобные старые версии без причины;
- не смешивать цитату и пересказ;
- не приписывать мотивы без маркировки `HYPOTHESIS`;
- не исправлять старую запись задним числом без объяснения изменения.
