## Ограничение текущего GitHub-коннектора
Малые бинарные blobs переносятся корректно. Большие base64-пакеты через текущий интерфейс могут быть обрезаны транспортом, поэтому крупный файл нельзя считать перенесённым без проверки SHA/Git blob. Для бинарного архива используется поэтапная запись и обязательная сверка, а не фиктивный статус «готово».

## Правило статуса
`migrated` означает, что содержимое реально записано в GitHub. Manifest, описание или локальный файл сами по себе не считаются переносом бинарного источника.
