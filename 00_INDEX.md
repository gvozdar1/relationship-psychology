# Индекс проекта

## Цель
Сделать репозиторий внешней проверяемой памятью по психологии отношений: хранить исходники, хронологию, наблюдения, гипотезы и решения так, чтобы анализ можно было перепроверить.

## Карта
- `README.md` — правила проекта.
- `01_METHOD.md` — метод анализа.
- `02_TIMELINE.md` — единая хронология.
- `03_HYPOTHESES_AND_CONFIDENCE.md` — гипотезы и уверенность.
- `04_SIGNAL_MATRIX.md` — сигналы и альтернативные объяснения.
- `05_COMMUNICATION_PROTOCOL.md` — разбор сообщений.
- `06_DECISION_MATRIX.md` — принятие решений.
- `07_UPDATE_PROTOCOL.md` — добавление новых данных.
- `08_SOURCE_REGISTRY.md` — каталог источников.
- `09_COMBINED_MASTER.md` — сводная версия после сверки.
