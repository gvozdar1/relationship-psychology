# Архив скриншотов текущего чата — 15.09.2026

## Назначение

Эта папка является отдельным архивным контуром для **скриншотов, реально приложенных к текущему чату**, если такие вложения существуют как доступные файлы.

## Результат проверки

**ФАКТ:** в файловой поверхности текущего разговора на момент аудита обнаружено `0` conversation-uploaded файлов.

Следовательно, в данном текущем чате нет доступных байтов скриншотов, которые можно честно перенести в этот архив.

## Что не считается вложением текущего чата

Project-backed файлы, доступные через контекст проекта, не являются автоматически вложениями этого конкретного разговора. Их нельзя копировать сюда только потому, что модель их видит в Project.

Исторический архив скриншотов проекта уже существует, в частности:

- `archive/snapshots/2026/08/23/kris-project/primary/screenshots/exact/`
- `archive/snapshots/2026/08/23/kris-project/primary/screenshots/partial/`

Эти исторические скриншоты не дублируются повторно без доказательства, что конкретный файл был приложен именно к текущему чату и ещё не архивирован.

## Правило дальнейшего пополнения

Если в этом разговоре появится новый скриншот как физически доступное вложение:
1. сохранить оригинал без преобразования;
2. записать исходное имя/идентификатор;
3. по возможности зафиксировать SHA-256;
4. связать его с сообщением/датой и соответствующим `SRC-*`;
5. не использовать наличие файла как доказательство смысла до содержательного разбора.
