## Текущий вывод

Блокировка находится на уровне запуска GitHub Actions job/runner/аккаунта/репозитория, а не на уровне Fish Audio API: все три run создаются, но завершаются до выполнения пользовательских шагов. Поэтому наличие и валидность `FISH_API_KEY` в самом Fish Audio API ещё не проверены.

Вероятные классы причины, которые должен показать интерфейс GitHub Actions: Actions disabled, исчерпан/заблокирован лимит минут, billing/spending limit, ограничение private-repo Actions или иная инфраструктурная блокировка GitHub.

## Правило безопасности

- API-ключи никогда не коммитить в репозиторий и не сохранять в `sources/chat/`.
- Для рабочего запуска использовать GitHub Repository Secret с именем `FISH_API_KEY`.
- Значение ключа, переданное в чат, считать чувствительным и не воспроизводить в ответах/файлах.
