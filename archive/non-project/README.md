# Вне активного проекта

Здесь сохранены материалы «Семейного пантеона» и связанные с ним рабочие файлы. Они исключены из активной базы «Психология отношений с Крис», не используются как доказательства и не смешиваются с хронологией отношений.

Дата `undated` применена потому, что для этих художественных файлов нет подтверждённой даты события, а подставлять дату коммита было бы выдумкой.
