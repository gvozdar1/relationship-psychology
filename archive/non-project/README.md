# Вне активного проекта

Здесь хранится отдельный творческий проект «Семейный пантеон» и связанные с ним рабочие файлы.

## Односторонняя связь проектов

Связь разрешена только в одном направлении:

`Психология отношений с Крис` → источник жизненных эпизодов, деталей, реплик и сюжетных мотивов → `Семейный пантеон`.

«Семейный пантеон» может искать материал для сюжетов в проекте «Психология отношений с Крис», прежде всего в `09_COMBINED_MASTER.md`, затем в `00_INDEX.md`, первичных источниках и `chronology/`.

Обратное направление запрещено: художественные тексты, главы, черновики, персонажи и интерпретации «Семейного пантеона» не являются источниками фактов, гипотез или доказательств для проекта «Психология отношений с Крис».

Основной корпус книги расположен в `archive/non-project/family-pantheon/`. Архивы рабочих сессий Пантеона остаются разложены по датам в `archive/non-project/2026/.../family-pantheon/chat-sessions/`.
