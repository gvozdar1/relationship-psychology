# Narrative layer

Этот раздел хранит художественные тексты, выросшие из материалов проекта `relationship-psychology`.

## Главное правило
Аналитическая база и художественный канон не смешиваются.

- Факты, источники, хронология и гипотезы живут в корневых аналитических файлах проекта.
- Художественные сюжеты, фантастические вставки, мифология, внутренние монологи и вымышленные диалоги живут только в `narrative/`.
- Художественная сцена может быть вдохновлена реальным эпизодом, но не становится доказательством того, что этот эпизод происходил именно так.

## Структура
- `00_STORY_BIBLE.md` — правила художественного канона, персонажи, тон и границы.
- `main_story/` — основная повесть и крупные главы.
- `mini_stories/` — самостоятельные мини-сюжеты и боковые сцены.
- `drafts/` — рабочие версии, которые ещё не считаются каноном.
- `audio_scripts/` — версии текстов, подготовленные для многоголосой озвучки.

## Рабочий процесс
1. Реальные события и новые материалы сначала фиксируются в аналитической части проекта.
2. На их основе создаётся художественная сцена в отдельной ветке `story/...`.
3. После проверки готовый текст переносится в соответствующий раздел `narrative/`.
4. Только слитая в `main` версия считается действующей художественной версией.
