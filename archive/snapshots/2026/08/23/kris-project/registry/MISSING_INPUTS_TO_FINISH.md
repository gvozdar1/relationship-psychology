# Что ещё требуется для полного завершения

## Обязательное

1. Один архив экспорта данных ChatGPT, содержащий разговоры аккаунта, либо отдельные полные экспорты всех 13 проектных чатов.
2. Повторные оригиналы семи проблемных скриншотов:
   - `1000028977.jpg`;
   - `1000029031.jpg`;
   - `1000029183.jpg`;
   - `1000029293.jpg`;
   - `1000029302.jpg`;
   - `1000029372.jpg`;
   - `1000029377.jpg`.

## Что пользователю не требуется делать

- вручную читать и сортировать 13 чатов;
- переименовывать файлы;
- сводить хронологию;
- искать дубли;
- править master.

После получения одного полного экспорта все перечисленные операции выполняются внутри проекта.

## Критерий завершения

Работа считается законченной только когда:

- все 13 веток идентифицированы по внутреннему ID и названию;
- для каждой сохранён полный транскрипт;
- сообщения объединены в хронологию без дублей;
- первичные материалы связаны с эпизодами;
- master обновлён и не противоречит источникам;
- итоговый архив проходит проверку SHA-256.
