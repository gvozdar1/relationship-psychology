# Baseline archive

Здесь сохранён неизменённый снимок исходного `09_COMBINED_MASTER.md`, который был загружен в проект до синхронизации GitHub.

Исходный файл: `/mnt/data/09_COMBINED_MASTER.md`, 746 строк, 38 249 байт на момент переноса.

Из-за ограничений коннектора снимок сохранён четырьмя последовательными UTF-8 частями:

1. `09_COMBINED_MASTER.baseline.part01.md`
2. `09_COMBINED_MASTER.baseline.part02.md`
3. `09_COMBINED_MASTER.baseline.part03.md`
4. `09_COMBINED_MASTER.baseline.part04.md`

Для восстановления исходного baseline части нужно объединить строго в этом порядке без вставок между ними.

Текущий корневой `09_COMBINED_MASTER.md` является развиваемым мастер-документом репозитория и содержит более поздние обновления. Этот каталог существует для того, чтобы исходное состояние мастера не было потеряно при обновлениях.
