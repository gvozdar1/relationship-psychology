# Экспорт текущего чата — 15.09.2026

Этот каталог хранит пользовательскую часть текущего проектного чата в JSON.

## Что лежит здесь

- `user-visible-transcript.json` — индекс экспорта, 23 последовательных user/assistant сообщения до команды пользователя на экспорт.
- `parts/part-001.json` — сообщения 1–6.
- `parts/part-002.json` — сообщения 7–12.
- `parts/part-003.json` — сообщения 13–16, включая исходный большой диалог 29.05 без редакционного сокращения в пользовательском сообщении.
- `parts/part-004.json` — сообщения 17–23, включая GitHub/AI Psychiatry-аудиты и текущую команду на экспорт.
- `coverage-manifest.json` — карта более ранней части большого чата, которая после сжатия контекста уже не доступна этому запуску как сырой дословный поток; она связана с уже существующими `SRC-*` файлами проекта.

## Что намеренно НЕ экспортируется

- system/developer инструкции;
- скрытые рассуждения модели;
- внутренние tool calls и их аргументы;
- служебные runtime-метаданные.

Это не часть пользовательского чата и не должна становиться источником проекта.

## Доказательный статус

Текст в `parts/*.json` хранится как user-visible transcript текущего доступного окна. Более ранние материалы, которые представлены только через `SRC-*`, сохраняют свой исходный статус: `primary`, `quoted-dialogue`, `user-report`, `reconstruction`, `secondary analysis` и т. п. Карта источников не превращает реконструкцию в дословную первичку.

Главный источник истины проекта остаётся `09_COMBINED_MASTER.md` по существующей иерархии проекта.
