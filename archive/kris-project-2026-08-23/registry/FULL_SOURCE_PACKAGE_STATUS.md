# Full source package

## Статус
Подготовлен локальный канонический source-only архив проекта:
`relationship-psychology-full-sources-2026-08-03.tar.xz`.

Он **не считается мигрированным в GitHub**, пока сам бинарный `tar.xz` не записан в репозиторий/asset-хранилище и не проверена контрольная сумма.

## Содержимое staging-пакета
- 161 уникальный канонический исходный скриншот в `sources/screenshots/originals/`;
- `messages12.html`;
- текстовые ветки переписки, физически доступные в локальном пакете;
- `1000029050.mp4`;
- baseline-документы проекта (`00`, `01`, `02`, `03`, `05`, `09`, `10`–`13`) в их локальном исходном состоянии;
- `screenshots_original_manifest.csv`;
- `PACKAGE_MANIFEST.json` с SHA-256 каждого файла внутри staging-каталога.

## Зачем пакет существует
Это единый физический контейнер первички на случай, если станет доступен прямой upload бинарного файла. Он не заменяет человекочитаемую структуру репозитория, а служит резервной копией исходного набора.

## Правило
Наличие этого описания подтверждает только подготовку локального пакета. До фактической передачи `tar.xz` в GitHub его статус остаётся `local-prepared / binary-pending`.
