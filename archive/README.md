# Архив

Архив хранит прежние срезы, пакеты импорта и заменённые рабочие версии. Он нужен для проверяемости истории, но **не является текущим каноном**.

- `ingested/YYYY/MM/DD/` — исходные пользовательские пакеты без смысловой переработки;
- `snapshots/YYYY/MM/DD/` — исторические состояния базы;
- `audits/YYYY/MM/DD/` — отчёты о переносе и целостности;
- `superseded/YYYY/MM/DD/` — старые производные сводки, заменённые более точными;
- `non-project/` — сохранённые материалы, не относящиеся к активному проекту.

Точные дубли после проверки 15.09.2026 оставлены в единственном экземпляре; в исторических манифестах вместо удалённых копий стоят указатели на сохранённый файл.
