# References

Здесь хранятся библиография, конспекты и проверяемые психологические модели.

## Предпочтительный формат
Для каждой книги/статьи:
- полная библиографическая ссылка;
- ключевые понятия;
- что подтверждается исследованиями;
- ограничения модели;
- практическая применимость к разбору отношений;
- отдельные цитаты только в допустимом объёме;
- наши выводы отдельно от авторского текста.

Полные книги лучше не хранить в репозитории без права на распространение. Для работы достаточно заметок, библиографии и разрешённых/собственных копий источников.
